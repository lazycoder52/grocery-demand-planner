# grocery-demand-planner

Demand-planning toolkit for grocery/FMCG retail built on the public Corporación
Favorita "Store Sales - Time Series Forecasting" data (Ecuador): forecasting,
promotion-effect analysis, replenishment simulation, assortment-gap analysis and
a Streamlit app.

Status: under construction.

## Data

The raw data is not included in this repository. See [data/README.md](data/README.md)
for download instructions.
